# Dataset Card — AgentShiftBench v0.2.0

## Summary
Synthetic, reproducible episode-level records generated by a controlled simulator for evaluating tool-using agent policies under tool/environment drift.

## Intended use
Research prototyping, teaching, baseline comparison, and reproducibility experiments on simulated tool-contract and runtime changes.

## Out-of-scope use
Do not use as a direct estimate of production incident probability, as a safety certification, or as evidence that a policy is safe for real tools.

## Composition
Six synthetic task templates; nine drift categories; three rule-based policies. Episodes cycle through all 54 task and drift pairs. The released result CSV is produced by running the CLI.

## Collection process
No human or customer data is collected. All records are generated locally by deterministic Python code using user-specified random seeds.

## Bias and limitations
Task and drift coverage is small and authored by the project researcher. The simulator may encode assumptions favorable to the guard. Independent review, expanded scenario coverage, and real trace validation are required for stronger claims.

## Maintenance
Version 0.2.0. Future versions should add API drift types, calibrated uncertainty, and real framework adapters without executing external side effects.
